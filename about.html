03 / THE STORY

About this project.

A simple website made to practise the foundations of web development.

ABOUT THE CREATOR

Hello, I'm Zetxion.

I'm a student learning about computers, web design, and creative technology. I made this portfolio as a place to present my work, share a small gallery, and practise building multiple linked web pages.

WHAT I LEARNED

Building blocks of the web.

01

HTML

HTML gives a web page its structure: headings, paragraphs, links, images, and forms.

02

CSS

CSS controls the visual style, including colours, spacing, layout, and mobile responsiveness.

03

Navigation

Separate HTML files can be connected with links so visitors can move between pages.

PROJECT PURPOSE

Learn by making.

The goal is to practise basic website design and make a clear, easy-to-use portfolio. The gallery and feedback form are demonstrations; the feedback form does not save messages to a server.
